# **Project Requirements** 

## **1. Team & Project Selection** 

- Each team must consist of **5–7 students** . 

## **2. Technical Requirements** 

Each project must include: 

1. **Data Collection:** Obtain a relevant dataset and document its source. 

2. **Data Preprocessing:** Inspect and clean the data, handle missing values where necessary, and prepare it for analysis. 

3. **Apache Spark / PySpark:** Use Spark meaningfully for data processing, such as filtering, aggregation, joins, DataFrames, or Spark SQL. 

4. **Data Analysis:** Perform Exploratory Data Analysis (EDA) and identify meaningful patterns. 

5. **Project-Specific Analysis:** Apply a suitable analytical or Machine Learning method according to the selected idea. Evaluate models when applicable. 

6. **Interactive Dashboard:** Build a dashboard that presents the project's findings through relevant KPIs, charts, and interactive filters or selections. 

## **3. Recommended Dataset Sources** 

Use these platforms to find datasets related to your chosen idea: 

**Kaggle:** <u>https://www.kaggle.com/datasets</u> 

**UCI Machine Learning Repository:** <u>https://archive.ics.uci.edu/datasets</u> 

**Google Dataset Search:** <u>https://datasetsearch.research.google.com/</u> 

**Hugging Face Datasets:** <u>https://huggingface.co/datasets</u> 

**AWS Open Data:** <u>https://registry.opendata.aws/</u> 

**World Bank Open Data:** <u>https://data.worldbank.org/</u> 

**NOAA Climate Data:** <u>https://www.ncei.noaa.gov/</u> 

**NASA Open Data:** <u>https://data.nasa.gov/</u> 

## **4. Interactive Dashboard Requirements** 

The dashboard must: 

- Present the project title and a brief description. 

- Include meaningful KPIs and appropriate visualizations. 

- Allow users to interact with the data through relevant filters or selections. 

- Display important findings and, when applicable, model results. 

- Be clear, organized, and functional. 

**Suggested tools:** Streamlit, Plotly Dash, Power BI, or Tableau. 

**Note:** Using a dashboard tool does not replace the requirement to use PySpark / Apache Spark for data processing. 

## **5. Final Deliverables** 

Each team must submit: 

- Source code or Jupyter Notebook. 

- Dataset or working dataset link, with proper attribution. 

- Working interactive dashboard. 

- A concise report explaining the problem, dataset, methodology, Spark usage, results, dashboard, and conclusion. 

- Presentation/demo and a README containing setup and running instructions.
